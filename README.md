A browser-based project that visually simulates a standard nutrition facts label.
It presents serving size, calories, macro- and micronutrients, and daily value percentages in a format familiar from packaged foods.

📌 Overview
This project recreates a nutrition facts label using HTML and CSS.
It shows serving size, calories, fat, cholesterol, sodium, carbohydrates, sugars, protein, and key vitamins/minerals.
The layout mimics the bold typography, dividers, and indentation used in official food labels.

🚀 Features
Clear header with “Nutrition Facts” and serving details
Calories per serving highlighted in bold
Macro- and micronutrients with daily value percentages
Indented sections for subcategories like Saturated Fat, Added Sugars, and Trans Fat
Notes explaining the % Daily Value
Fully responsive and styled with semantic HTML and CSS

🛠 Technologies Used
HTML5 – Structure and semantic layout
CSS3 – Typography, spacing, and styling
Google Fonts – Open Sans for a clean, readable label
Flexbox – For aligned nutrition values and totals

⚙️ How It Works
The header shows the title, servings per container, and serving size.
Calories are emphasized separately for easy visibility.
Each nutrient line displays the nutrient name, amount per serving, and its % Daily Value.
Indentation and dividers visually separate main nutrients from subcategories.
A note at the bottom explains the % Daily Value reference based on a 2,000-calorie diet.
